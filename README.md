> ## 核心理念：技术与商业的翻译官
>
> **“单点模型的强大，并不等同于企业级生产力。”**
> 本作品集不仅是一份网页化简历，更是一份展示“如何把技术卖出去、用起来”的微型商业企划书：
>
> * **高维解构能力**：面对复杂的企业级需求，能迅速剥离技术自嗨，回归利润表（开源）、现金流（节流）与风控底线（避险）。
> * **数据驱动闭环**：强调过程留痕与结果量化，熟练运用 TCO（总拥有成本）建模、SLA 保障、转化率与 ROI 测算进行价值论证。
> * **架构与业务双修**：从 AI Agent 的底层提示词工程，到 B2B2B 的复杂多租户权限隔离（IAM），具备极强的技术理解力与跨频道沟通能力。

> ## 核心项目阵列 (Featured Projects)
>
> ### 1. Pre-Flight AI 智能助手 (AI Agent)
> * **定位**：基于百度千帆 AppBuilder 独立研发的 AIGC 视频生成前置检查工具。
> * **核心动作**：设计三级合规拦截机制，优化底层工作流编排。
> * **业务价值**：将端到端响应时间从 70s 压缩至 42.3s，大幅提升安全检查效率与系统健壮性。
>
> ### 2. AI 老年陪伴端云解决方案 (AI Hardware + Cloud)
> * **定位**：为 AI 硬件厂商设计的基于百度智能云的端云一体化售前方案。
> * **核心动作**：参与客户真实需求调研，完成云端大模型与边缘端算力的技术选型与架构演示。
> * **业务价值**：端侧打断与响应延迟优化至 1.3s，成功消除硬件产品经理对“交互体验红线”的顾虑，推进商机落地。
>
> ### 3. AI 漫剧 ISV 渠道合作方案 (AIGC & Channel Sales)
> * **定位**：针对头部 AI 漫剧平台的云资源与生视频大模型渠道拓展。
> * **核心动作**：识别并直击业务一号位对“被原厂撬单”的核心恐惧。
> * **业务价值**：通过设计 IAM 主子账号架构与严密的权限隔离机制，成功化解客户商业顾虑，推动合作意向达成。
>
> ### 4. HPE dHCI 金融行业解决方案 (Cloud Architecture & TCO)
> * **定位**：为模拟金融客户量身定制的 HPE GreenLake 混合云方案。
> * **核心动作**：敏锐发现客户“存储与计算非对称增长”的业务锚点，以客户自身真实数据驳斥竞品假设。
> * **业务价值**：完成严密的 TCO（总拥有成本）价值论证，在提升 4 倍性能的同时，为客户压降 20% IT 支出。
>
> ### 5. 岭北数码 · 智能零售与指标化运营 (E-commerce Operations)
> * **定位**：从 0 到 1 独立操盘的二手数码电商项目闭环。
> * **核心动作**：通过信任解决方案设计（严格认证+SLA售后兜底）和数据驱动的精细化运营（A/B 测试、私域社群清洗）。
> * **业务价值**：实现客户转化率提升 30%，单月 GMV 突破万元，沉淀了极强的泛流量漏斗转化思维。

> ## 仓库结构 (Monorepo Architecture)
>
> 本作品集采用极简的单体仓库结构，易于维护与扩展：
>
> > ```text
> > /
> > ├─ index.html              # 核心单页（结构/样式/交互）
> > ├─ images/                 # 全局共用静态资源（头像、Logo、项目配图）
> > ├─ projects/               # 各核心项目的独立复盘详情页
> > └─ thoughts/               # 商业思考、架构解析与项目复盘博文
> > 
> > ```
>

> ## 技术栈与实现细节
>
> - **前端实现**：原生 HTML5 + CSS3 + Vanilla JS，零框架依赖，极致轻量，完美适配 GitHub Pages 静态托管。
> - **视觉语言**：采用硅谷主流的极简排版、Bento Grid（四宫格 / 走马灯）模块化布局、Glassmorphism（玻璃拟态）卡片以及细腻的微交互光影。
> - **自适应与可访问性**：完美兼容移动端 / 平板 / 桌面端；支持全局“明/暗”双主题无缝切换。
